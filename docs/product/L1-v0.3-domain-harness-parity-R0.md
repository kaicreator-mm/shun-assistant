## 3. Reuse evidence and not-yet-proven matters

- `packages/authorization/src/controller.ts` exports `ActionController.authorizePlan` and `authorizeEffect`. Authorization capability exists; composing it with K is **NOT_RUN**.
- `packages/resolver/src/planner-seam.ts` exposes typed proposal handling, and `packages/llm-remote/src/planner-port.ts` supplies remote planner adaptation. Composition through genuine model response + separate human approval is not yet v0.2 closed.
- `apps/control-api/src/server.ts` exposes system-inventory/diagnosis and cloud/Recipe routes; routes alone are not an accepted end-user journey.
- DomainHarness v0.10.3's OpenAI-compatible C/Host and neutral `dh.llm.generate/1` are potential reuse; endpoint/key policy and actual release/consumer state remain Host/SDK qualifications. The documented Guided Journey example is **not** a complete UI engine.
