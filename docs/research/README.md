# Research Archive Boundary

The detailed raw research dataset currently lives in the project's Google Drive workbook `AI Computer Assistant - L1 Product Evidence - 5 Rounds`.

It contains the raw/encoded evidence used to derive the canonical GitHub Product/L1 conclusions.

This external workbook is a **supporting evidence archive**, not project authority. Product decisions, PRD clauses, review gates, benchmark definitions, and freeze state are authoritative only when materialized on GitHub and bound to an exact commit SHA.

Do not make new Product claims from the raw workbook without materializing the resulting decision/change into GitHub and subjecting it to the applicable review gate.
