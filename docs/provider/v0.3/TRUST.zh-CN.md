# v0.3 Provider 安全、密钥保管与离线恢复（中文）

## 生产可信根

生产环境使用由运营方通过**受控 Windows Host 配置**预置的 Curator 公钥、keyId 和 Scope binding。它们不能从 Goal、Planner、浏览器、远程下载元数据或未验证的配置文件获取。

密钥管理：
- 私钥只用于独立的 Curator 签名流程，**不放入源码、环境包、CI 日志或客户端安装产物**。
- 客户端只含生产公钥及可追溯的指纹/轮换清单；测试固定密钥不能用于生产。
- 每次验证都绑定 Provider ID、Capability ID、平台、版本、Catalog Revision、准确 artifact SHA256 和依赖列表；签名与字节哈希不一致即拒绝。
- 发生泄露时先停用可信目录及相关执行，发布**经过批准的**新公钥和目录版本，再撤销旧根；未经批准不得自动切换备用根。
- 密钥、Provider ZIP、模型响应及诊断日志应按最小保留原则处理。

## 离线模式

可信目录与 Provider 原始工件必须有可追溯缓存来源；仅在根、签名、摘要、兼容性与平台全部核验后允许离线重用。缺失缓存时返回 typed UNAVAILABLE，不得退回不受控网络地址、二次下载器或未签名可执行文件。权限不明时禁止加载/执行。

## 尚需验收

v0.3 正式 Windows 生产入口、真实公钥注入、离线安装恢复、版本打包、GBK/UTF-8 与端到端迁移仍需实际测试；没有真实证据的项一律 UNKNOWN。
